# Prototypes (not part of the graded build)
Hand-written experiments from before the manual was read closely. They do NOT use Flex/Bison and support only
`int`, `+ - * /`, `print`. The manual requires one fixed language (Section 5) built with Flex + Bison, which is
what `src/` implements. Kept for reference only; safe to delete.
`C_Compiler/lex.yy.cpp` and `parser.tab.cpp` are hand-written, not Flex/Bison output, despite the names.
